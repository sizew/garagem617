# Garagem 617 — Estética Automotiva

Site institucional, vitrine técnica de serviços e fluxo de orçamento e agendamento direto pelo WhatsApp para a **Garagem 617 Estética Automotiva** (Jardim Presidente Dutra, Guarulhos - SP).

## Stack

- React 19
- TypeScript
- Vite 8
- CSS Modules

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Deploy na Vercel

O projeto já inclui `vercel.json` configurado para Vite (`npm run build` com saída em `dist` e rewrite para SPA). Basta importar o repositório do GitHub diretamente no painel da Vercel e publicar.
